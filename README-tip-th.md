# เลือกยอดทิปและสร้าง QR พร้อมเพย์

เพิ่มปุ่ม 20, 50, 100, 1,000 บาท และกำหนดเอง (0.01–999,999.99 บาท)
เลือกยอดแล้ว QR จะเปลี่ยนทันที พร้อมบันทึกรูป PNG สำหรับใช้บนมือถือเครื่องเดียวกัน

## ผู้รับเงิน

ข้อมูลผู้รับถอดจาก `qr.JPG` เดิมโดยตรง: PromptPay merchant tag 29,
รหัสประเภท 03 (e-Wallet ID) `004999085797768` ไม่ใช่เบอร์โทรหรือเลขบัญชีธนาคาร
ชื่อแสดงอ้างอิงจากรูปเดิม: นาย ชินดนัย เรืองสมบัติ
ไม่ต้องสมัครบัญชีรับเงินใหม่หรือเปลี่ยนผู้รับเพื่อใช้ฟีเจอร์นี้
ชื่อในหน้าเว็บเป็นข้อความประกอบ ชื่อที่แอปธนาคารแสดงเป็นข้อมูลที่ต้องตรวจสอบก่อนยืนยันโอน

## ติดตั้งในเว็บเดิม

นำ `index.html`, `promptpay.js`, `tip.js` และโฟลเดอร์ `vendor/` ไปวางแทน/เพิ่ม
ที่ตำแหน่งเดิมในโปรเจกต์ แล้ว deploy ตามขั้นตอนเดิมของเว็บ
ไม่มีการเปลี่ยน Supabase, ตารางฐานข้อมูล, หน้า DJ หรือ API แจ้งเตือน
ไม่ต้องติดตั้ง npm เพิ่มเพื่อสร้าง QR: ไลบรารี qrcode-generator 2.0.4 รวมอยู่ใน vendor แล้ว
ทดสอบด้วย `node --test tests/payment.test.cjs`

ก่อนใช้จริงให้ลองสแกนยอด 20 / 50 / 100 / 1,000 / กำหนดเองด้วยแอปธนาคาร
ตรวจสอบชื่อผู้รับและยอดให้ตรง แล้วทดสอบโอนยอดเล็กเพื่อยืนยันปลายทาง
ผู้พัฒนาฟีเจอร์ยังไม่ได้ยืนยันบัญชีปลายทางหรือทำธุรกรรมเงินจริง

## ขอบเขต

QR สร้างในเบราว์เซอร์ ไม่มีการเรียก API สร้าง QR ภายนอก
ใช้รหัสผู้รับเดิม พร้อมยอดเงินบาทและ CRC16 ตามรูปแบบ PromptPay
หากจำนวนเงินไม่ถูกต้อง QR เดิมจะถูกซ่อนเพื่อป้องกันสแกนยอดเก่า
รหัสอ้างอิงในรูปเดิมไม่ใช่รหัสธุรกรรมใหม่สำหรับแต่ละทิป
QR นี้ไม่ได้สร้างเลขอ้างอิงคำขอเพลงหรือยืนยันว่าเงินเข้าแล้ว
ระบบขอเพลงยังทำงานแยกจากการทิปเช่นเดิม
การตรวจยอดเข้าและจับคู่กับเพลงต้องเพิ่มระบบตรวจชำระเงินต่างหาก
